# Fonts

Latin subsets of three Google Fonts, hosted with the site so pages draw with
the right type straight away and work offline:

- **Big Shoulders Display** (variable, weights 700–900) by Patric King
- **Barlow** (400, 500, 600) by Jeremy Tribby
- **IBM Plex Mono** (400, 500) by IBM / Mike Abbink

All three are licensed under the SIL Open Font License 1.1:
https://openfontlicense.org
